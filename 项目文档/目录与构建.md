# 目录与构建

文档集中在项目文档；必要源文件、配置及文本测试输入保留原路径。GitHub 的固定平台入口保持标准位置，文档区也保存完整副本。

从仓库根目录运行 `python3 构建.py --stage --ci`，得到 `Build/源码`，其中恢复原文档输入供既有相对路径检查使用。`--build` 每次在 `Build/新构建` 创建独立源码、缓存、日志及产物。Python 构建需要解释器中已有 build 模块；CMake、npm、Cargo、Go 按项目 kind 选择。未适配的项目返回 OPEN_MANUAL_ADAPTER，仅完成暂存，不启动原有安装或启动脚本。

Build 不提交到 Git；历史发行包与版本保留，本次提交只整理路径和构建配置。旧验证报告对应原提交，不代表新目录已完成运行验证。
